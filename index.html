01 / Personal project

StoreFlow

Retail sales reconciliation & validation

Sales files can contain duplicate transactions, invalid identifiers, and totals that don’t reconcile. I built a Python pipeline that stages the original data, loads accepted records into PostgreSQL, and preserves rejection details for investigation.

The result: a Streamlit dashboard that connects sales reporting with pipeline status, data-quality checks, and source-record traceability.
